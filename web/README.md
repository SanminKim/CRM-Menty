# Веб-версия CRM (страница в Claude)

`index.html` — вся CRM одной страницей. Она опубликована как артефакт в Claude и хранит данные во встроенной базе артефакта, сервер не нужен.

Этой версией можно пользоваться уже сейчас. Django-версия в корне репозитория — для переезда на свой сервер, когда поток вырастет.

## Как устроено

- Разметка, стили и скрипт лежат в одном файле, без сборки.
- Данные читаются и пишутся через `claude.use("db")`. Коллекции: `students`, `cohorts`, `partners`, `payouts`, `team`, `reports`, документ `config/main`.
- Платежи, отклики, заметки и история этапов хранятся внутри документа студента.
- Отчёт для партнёра — отдельный документ в `reports`. В нём только цифры и сокращённые имена, без контактов.

## Права доступа

Страница публикуется с такими возможностями:

```json
{
  "db": {"rules": [
    {"path": "", "read": "interact", "write": "interact"},
    {"path": "reports", "read": "view", "write": "interact"}
  ]},
  "user": {"scopes": ["profile"]},
  "downloads": true
}
```

- Редакторы и участники с правом изменения читают и пишут всё.
- Зрители (блогер) читают только `reports`.

## Как обновить опубликованную страницу

Правки в этом файле сами в Claude не попадают. После изменения попросите Claude в чате проекта подтянуть код из репозитория и переопубликовать страницу. Данные в базе при этом сохраняются.

## Локальный просмотр

`dev/mock.js` подменяет `window.claude` и хранит данные в `localStorage` браузера. Чтобы открыть страницу локально, оберните `index.html` в обычный HTML-документ и подключите `dev/mock.js` в `<head>` перед содержимым страницы. Параметр `?role=partner` показывает страницу глазами блогера.
