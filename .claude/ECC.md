# Что взято из ECC

Источник: https://github.com/affaan-m/ECC, версия 2.2.3, коммит `ef648e0`. Лицензия MIT, текст — в `ECC-LICENSE`.

ECC — большой набор для Claude Code: 68 агентов, 293 навыка, 94 команды, хуки и правила для двух десятков языков. В проект взята только часть, которая подходит под Django, PostgreSQL и Docker. Файлы скопированы без изменений.

## Агенты (`.claude/agents/`)

| Агент | Зачем |
|---|---|
| `planner` | план реализации перед началом работы |
| `architect` | архитектурные решения |
| `tdd-guide` | разработка через тесты |
| `code-reviewer` | ревью любого изменения |
| `python-reviewer` | ревью Python-кода |
| `django-reviewer` | ревью моделей, представлений, запросов Django |
| `database-reviewer` | ревью схемы, миграций, запросов |
| `security-reviewer` | проверка безопасности |
| `django-build-resolver` | разбор ошибок запуска, миграций, зависимостей |

## Навыки (`.claude/skills/`)

`django-patterns`, `django-security`, `django-tdd`, `django-verification`, `python-patterns`, `python-testing`, `postgres-patterns`, `database-migrations`, `docker-patterns`, `security-review`, `tdd-workflow`, `verification-loop`.

## Команды (`.claude/commands/`)

`/plan`, `/code-review`, `/python-review`.

## Что не взято и почему

- **Хуки.** Запускают скрипты ECC на каждое действие и требуют полной установки. В README самого ECC описан вариант без них.
- **Правила `rules/`.** Написаны под другой стек и расходятся с проектом: pytest вместо встроенного раннера Django, обязательные 80% покрытия, английские типы коммитов. Нужное из них перенесено в `CLAUDE.md` в корне.
- **Остальные агенты, навыки и команды.** Относятся к другим языкам и задачам. Описание каждого навыка загружается в каждый сеанс, поэтому лишние только мешают.
- **MCP-серверы.** Проекту не нужны.

## Как обновить

Скопировать нужные файлы из свежей версии ECC поверх текущих и исправить версию и коммит в начале этого файла. Перед обновлением просмотреть изменения: это инструкции, которые агент будет выполнять.

## Полная установка на своём компьютере

Разработчик, который работает в Claude Code локально, может поставить ECC целиком как плагин по инструкции из README ECC. Это отдельно от файлов в этой папке. Одновременно полный плагин и эти файлы дадут дубли агентов и навыков, поэтому выбирают что-то одно.
